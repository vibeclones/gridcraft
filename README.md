# gridcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [gridcraft](https://github.com/storytold/gridcraft), a Excel-style spreadsheet by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/gridcraft/latest/`
- Specific version: `/gridcraft/v<version>/`
- Version list: `/gridcraft/versions.json`

Each version folder is the unmodified contents of upstream's `gridcraft-web-<version>.zip` release asset, including its license files. Upstream license: Apache-2.0. A scheduled workflow mirrors new releases.
